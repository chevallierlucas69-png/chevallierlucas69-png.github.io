INSTALLATION WINDOWS

Comment installer le launcher

Important : débloquez le fichier ZIP avant de l’extraire pour éviter le message « fichier potentiellement dangereux » de Windows.

  1. 1TéléchargezRécupérez NightcoreLauncher.zip.
  2. 2Débloquez le ZIPClic droit sur NightcoreLauncher.zip → Propriétés → Général → cochez Débloquer → Appliquer.
  3. 3Extrayez toutClic droit sur le ZIP → Extraire tout.
  4. 4InstallezDans le dossier extrait, lancez INSTALLER LE LAUNCHER.cmd.
